## 4. 参数互斥与快捷方式

### 4.1 `--range` vs `--date` 互斥

```bash
# ❌ 报错：--range 与 --date 不能同时传
python main.py --biz_key "X" --range last_7d --date 2026-08-12

# ✅ 正确二选一
python main.py --biz_key "X" --range last_7d
python main.py --biz_key "X" --date 2026-08-12
```

可选 `--range` 值：
- `last_1d`（昨天）
- `last_3d`
- `last_7d` ⭐ 最常用
- `last_15d`
- `last_30d`

### 4.2 h5st 预校验（2026-08-12 新增）

如果跑京准通/京麦业务**没传 `--h5st`**，脚本会在执行前打印：

```
[WARN] 以下业务需要 --h5st，但 CLI 未传入：
  - 京准通快车自定义报表
  - 京准通全站营销单品计划
  - ...
请按以下步骤获取 h5st：
  1. 浏览器登录对应域（jzt.jd.com / shop.jd.com）
  2. F12 → Network → 抓 add / createExportTask 请求
  3. 复制请求头 h5st 字段值
  4. 重跑命令并加 --h5st "<h5st值>"

是否继续（不传 h5st 跑这些业务可能 code=0 / 鉴权失败）？[y/N]
```

输入 `y` 继续尝试（可能失败），输入 `N` 退出（推荐）。

## 5. 常见错误速查

| 错误现象 | 原因 | 修复 |
|---------|------|------|
| `Cookie文件不存在: config/sz_cookie.txt` | 没抓 cookie | 浏览器 F12 抓 sz.jd.com 域 cookie 写入文件 |
| `Cookie已过期` | cookie 失效 | 重抓 |
| 京准通 `code=0` 空响应 | h5st 过期 / 没传 | 重抓 h5st + `--h5st` |
| 京准通 `code=-407 不安全的请求` | User-mnp 签名错 | 极少见；先重跑 |
| 京准通 `code=601 操作频繁` | 风控拦截 | 停 30-120 分钟，换 IP |
| 京麦 IMAP 5 分钟超时 | 短信没收到 / 邮件主题错 | 查 QQ 邮箱 `INBOX` 主题含「解压密码」或「京东」的邮件；用 `--sms_password` 重跑 |
| 商智 `0 字节`响应 | Cookie 缺新版 flash 字段 | 重抓 cookie（确保含 `flash=3_...`） |
| `KeyError: '京麦售后明细_完整一键导出'` | 没装最新 main.py | `git pull` 或 `git log` 确认 commit ≥ 217cda0 |

## 10. AuthLoader 使用指南（2026-08-13 新增）

> 适用场景：影刀 RPA 抓取 Cookie/h5st 后用 JSON 写入文件，Python 自动读取 + 过期检查 + 触发 RPA 重抓。

### 10.1 启用方式

```bash
# Windows PowerShell
$env:AUTH_LOADER = "1"
$env:SHOP_ID = "FYA箱包旗舰店"
$env:AUTH_RPA_CLI = "yingdao.exe"   # 影刀路径（默认占位，未安装仅 warning）
$env:AUTH_RPA_TASK = "jd_refresh"   # 影刀任务名（默认）

# 然后跑业务（与之前命令相同）
python main.py --biz_key "京麦售后明细_完整一键导出" --date "2026-08-12" --h5st "..."
```

### 10.2 配置文件格式

**Cookie（浏览器 DevTools 导出格式）**：
```json
{
  "url": "https://shop.jd.com/jdm/trade/orders/order-list?tabType=allOrders",
  "cookies": [
    {"name": "shshshfpa", "value": "...", "domain": ".jd.com", "path": "/", "expires": 1821121158, "sessionCookie": false},
    {"name": "pin", "value": "FYA8888", "domain": ".jd.com", "path": "/", "expires": -1, "sessionCookie": true},
    ...
  ]
}
```

**h5st（影刀写入格式）**：
```json
{
  "h5st": "20260813145522965;ijn5jin75aebjn54;...",
  "captured_at": 1786524917965,
  "ua": "Mozilla/5.0 ...",
  "biz_domain": "jzt.jd.com"
}
```

### 10.3 过期检查规则

| 字段 | 检查方式 | 过期时行为 |
|------|---------|----------|
| Cookie `expires` | `now > expires` | 抛 `CookieExpiredError` + 触发 RPA |
| h5st `captured_at` | `now - captured_at > 1800s` | 抛 `H5stExpiredError` + 触发 RPA |
| Cookie `sessionCookie: true` | 跳过（关闭浏览器即失效，但无法精确判断） | 无 |

### 10.4 调试命令
