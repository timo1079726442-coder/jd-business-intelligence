### 11.4 Bug 修复流程

1. **报错定位** → 看 `logs/jd_api_YYYYMMDD.log` 末尾堆栈
2. **接口风控**（601/403）→ 检查 cookie + h5st + uuid 前缀，参考 `全局复利的踩坑日志.md`
3. **业务逻辑** → 修改对应业务类，**不要**直接动 `JDBaseRequest`
4. **数据库** → 检查 `db_utils.save_to_db` 调用，主键配置在 `config.xlsx`
5. **回归测试** → 修改后跑对应 `tests/test_*.py`，**全绿才能提交**
6. **写变更记录** → 更新 `docs/API 实现逻辑说明.md` 或对应 Skill
