# 📂 文件夹命名说明：docs

## 基本信息

| 项 | 内容 |
|---|------|
| **文件夹名** | `docs` |
| **命名含义** | "文档（Documents）"的缩写（去掉元音更简洁） |
| **完整含义** | 项目文档目录 |
| **位置** | 项目根目录 |
| **创建原因** | 集中存放项目说明文档，与代码隔离，便于查阅 |

## 用途

存放项目技术文档：

| 文件 | 作用 |
|------|------|
| `API 实现逻辑说明.md` | 每个API接口的完整实现逻辑、字段映射、风控处理 |
| `JZT_KUAICHE_SKILL.md` | 京准通快车自定义报表业务沉淀（接口/状态码/踩坑/变更记录） |
| `项目API清单.xlsx` | API清单Excel（含5个工作表：接口总览/字段明细/返回字段/风控参数/返回分类） |
| `项目文档索引.xlsx` | 项目文档索引（由 `create_doc_index_xlsx.py` 生成） |
| `FOLDER_NAME.md` | 本文件（命名说明）|

## 命名规范

✅ 通用命名：`docs/` 是业界标准目录名（GitHub、Python等都约定）
✅ Markdown格式（`.md`）+ Excel格式（`.xlsx`）混合存储
❌ 不放临时文件（临时文件放根目录或删除）
