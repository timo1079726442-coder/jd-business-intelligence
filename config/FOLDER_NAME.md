# 📂 文件夹命名说明：config

## 基本信息

| 项 | 内容 |
|---|------|
| **文件夹名** | `config` |
| **命名含义** | "配置（Configuration）"的缩写 |
| **完整含义** | 项目配置文件目录 |
| **位置** | 项目根目录 |
| **创建原因** | 集中存放所有可配置项（Cookie、Excel配置、业务参数），方便修改、不污染代码 |

## 用途

存放项目运行所需的配置文件：

| 文件 | 作用 | 注意事项 |
|------|------|---------|
| `cookie.txt` | 京东商智登录Cookie | ⚠️ 已加入 `.gitignore`，**禁止上传GitHub** |
| `jzt_cookie.txt` | 京准通（jzt-api.jd.com）登录Cookie | ⚠️ 已加入 `.gitignore`，**禁止上传GitHub** |
| `config.xlsx` | 业务参数配置（日期、渠道ID、盐值、间隔等） | 公开可上传 |

## 命名规范

✅ 通用命名：`config/` 是业界标准目录名
✅ `.txt` 纯文本配置
✅ `.xlsx` Excel配置（小白友好，可视化编辑）
❌ 敏感文件必须加入 `.gitignore`
