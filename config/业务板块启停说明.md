# 业务板块启停配置

项目统一使用 `config.xlsx` 的「业务清单」工作表控制业务是否参与调度。

| 列 | 含义 |
|---|---|
| 业务 key | 调度脚本使用的业务名称，不能随意改名 |
| 调度批次 | `jm_jzt`（京麦/京准通）或 `sz`（商智） |
| 输出目录 | 报表保存目录 |
| 支持区间 | `是` 表示按区间补数，`否` 表示按日补数 |
| 默认粒度 | 例如 `day`；关键词等月度业务按实际接口能力配置 |
| 启用 | `是`=正常拉取，`否`=调度层跳过 |

## 停用一个板块

1. 打开项目 `config/config.xlsx`。
2. 进入「业务清单」工作表。
3. 找到要停用的业务行，把最后一列「启用」改为 `否`。
4. 保存文件。下次运行 `run_daily.py`、`refresh_reports.py` 或其他使用统一调度器的任务时，该业务会被跳过，不发起接口请求。

## 重新启用

将同一行「启用」改回 `是` 即可。不要删除业务行，这样可以保留历史表、字段映射和后续恢复能力。

店铺也可在 `config.xlsx` 的「店铺清单」工作表通过「启用」列控制；停用店铺时，该店铺下所有业务都会跳过。

业务表与用途的完整说明见项目 `output/数据库表业务映射.xlsx`。

配置表中的「启用」「是否启用」「支持区间」「默认粒度」「状态」字段已经加入下拉选择和非法值拦截；直接点击单元格即可选择，不需要手工输入。
