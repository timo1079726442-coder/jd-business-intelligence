# 📂 文件夹命名说明：.trae

## 基本信息

| 项 | 内容 |
|---|------|
| **文件夹名** | `.trae` |
| **命名含义** | Trae IDE的隐藏配置目录（点开头 = 隐藏目录） |
| **完整含义** | Trae Agent项目级配置目录 |
| **位置** | 项目根目录 |
| **创建原因** | Trae IDE规范：项目级Skill/规则都放在这个目录，与全局配置隔离 |

## 用途

存放Trae IDE识别的项目级配置：
- `skills/` - Skill库（按业务领域划分）
- 未来可能扩展：自定义命令、MCP配置等

## 命名规范

✅ Trae IDE自动识别 `.trae/` 目录为项目级配置
✅ 必须放在项目根目录
✅ 目录名以点开头（隐藏），不影响项目结构
