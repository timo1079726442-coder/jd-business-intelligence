# Git安全操作校验Skill
适用场景：涉及git命令、shell命令，尤其包含rm删除操作。

## 强制执行步骤
1. 逐词拆解命令，git参数、shell关键字全部给出中文释义，例如 commit、rm、‑f、--cached、;、2>/null。
2. 风险识别：
    - `git rm -f`：高危，物理删除本地磁盘源码；未commit的文件删除后git无法恢复。
    - `git rm --cached`：安全，仅从git追踪移除，本地磁盘文件原样保留。
    - `2>/null`：屏蔽报错，静默执行，发生问题用户看不到提示，属于隐患。
3. 输出【原命令风险总结】，明确哪些行为会造成代码丢失。
4. 给出安全等价改写版本。
5. 输出小白记忆区分对照表。

## 硬性规则
绝不允许直接执行 `git rm -f`；必须先说明风险，优先使用 --cached 安全方案。
