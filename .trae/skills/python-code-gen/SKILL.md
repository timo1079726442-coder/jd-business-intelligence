# Python代码生成Skill
适用场景：生成、修改、重构项目内main.py、jd_api/*.py脚本。

## 强制执行步骤
1. 代码固定结构：
    - 顶部import导入块，每个import写注释，说明库是干什么的。
    - 紧接着【业务配置区】，所有业务可调变量全部集中在此处。
    - 之后是业务逻辑代码。
2. 注释要求：
    - 英文函数、方法、参数、关键字，附带通俗中文解释。
    - 复杂代码块增加块注释，描述该块业务目的。
3. 安全约束：
    - Cookie、thor、User‑mnp、token等动态鉴权参数禁止硬编码；预留变量位置，加大段注释提醒用户抓包填入。
4. 代码输出完毕后，简短补充运行注意事项。
