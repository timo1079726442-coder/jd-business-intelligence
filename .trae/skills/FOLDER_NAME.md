# 📂 文件夹命名说明：skills

## 基本信息

| 项 | 内容 |
|---|------|
| **文件夹名** | `skills` |
| **命名含义** | "技能（Skills）"的复数形式 |
| **完整含义** | Trae Agent技能库目录 |
| **所属** | `.trae/` |
| **创建原因** | Trae IDE规定的Skill存放目录，按业务领域划分技能，避免规则互相干扰 |

## 用途

存放本项目用到的所有Skill。每个Skill是一个独立子目录：
- 按需加载（不每轮对话自动注入）
- 业务能力封装，按业务领域划分
- 防止agents.md臃肿、token浪费、规则失效

## 子文件夹清单

| 子目录 | 命名含义 | 用途 |
|--------|----------|------|
| `jd-api-analyze/` | 京东API分析 | 京东全系业务（商智/京麦/京准通）接口分析、知识沉淀 |
| `git-safe-operate/` | Git安全操作 | Git/shell命令安全校验，防御 `git rm -f` 高危删除 |
| `python-code-gen/` | Python代码生成 | 生成面向编程小白的Python代码 |

## 命名规范

✅ Trae IDE规定：所有Skill必须放在 `.trae/skills/` 下
✅ Skill子目录命名：`<业务领域>-<功能>`（小写+连字符）
❌ 不按单个项目/单个接口拆分Skill（防碎片化）
